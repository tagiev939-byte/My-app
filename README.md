# Assembly Empire

**3D-тайкун про фабрики для iPhone.** Добывайте руду, стройте конвейеры, плавьте металл, собирайте детали вплоть до роботов, покупайте новые земли и стройте свою промышленную империю.

## Скачать

Последняя неподписанная сборка: **Releases → latest → `AssemblyEmpire.ipa`**.

Установка на iPhone: [Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io) — они подпишут файл вашим Apple ID (бесплатный аккаунт — на 7 дней). Нужен iOS 16+.

## Что в игре

- Низкополигональный 3D-остров: вода, тени, освещение от неба, свечение печей, дым, анимированные конвейеры.
- Камера: один палец — двигать, щипок — приближать, два пальца — крутить и двигать.
- 7 зданий: конвейер, бур, печь, сборщик, сплиттер, перекрёсток, рынок.
- 19 видов товаров: от руды до роботов, 13 рецептов.
- Тайкун-механики: улучшение зданий (10 уровней), покупка 24 участков земли, контракты на поставки, ускорение ×2, доход пока игра закрыта, исследования.
- 17 целей с наградами, пошаговое обучение, музыка, звуки, вибрация, автосохранение.

## Сборка

При каждом пуше в `main` GitHub Actions:
1. генерирует Xcode-проект из `project.yml` (XcodeGen);
2. собирает неподписанный `AssemblyEmpire.ipa` и публикует его в релиз `latest`;
3. параллельно запускает игру в iOS-симуляторе в нескольких QA-сценариях и публикует скриншоты в релиз `screens`.

Локально на Mac: `brew install xcodegen && xcodegen generate && open AssemblyEmpire.xcodeproj`.

QA-сценарии запускаются аргументом `-scenario <name>`: `title`, `factory`, `inspector`, `build`, `closeup`, `land`, `upgrades`, `goals`, `menu`, `tutorial`, `wide`, `icons`.

## Структура

- `AssemblyEmpire/Model` — данные и симуляция (мир, рецепты, цели, контракты).
- `AssemblyEmpire/Render` — SceneKit: модели, текстуры, камера, рендерер.
- `AssemblyEmpire/UI` — SwiftUI-интерфейс.
- `AssemblyEmpire/Core` — контроллер игры, звук, точка входа.
- `AssemblyEmpire/Sounds` — синтезированные звуки и музыка.
