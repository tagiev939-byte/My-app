# Assembly Empire

Фабричная игра для iPhone на SwiftUI: добывайте руду, стройте конвейеры, плавьте металл, собирайте детали и продавайте их.

## Скачать

Последняя неподписанная сборка: **Releases → latest → `AssemblyEmpire.ipa`**.

Установка на iPhone: [Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io) — они подпишут файл вашим Apple ID (бесплатный аккаунт — на 7 дней).

## Сборка

При каждом пуше в `main` GitHub Actions:
1. генерирует Xcode-проект из `project.yml` через XcodeGen;
2. собирает приложение без подписи;
3. упаковывает `AssemblyEmpire.ipa` и публикует его в релиз `latest`.

Локально на Mac: `brew install xcodegen && xcodegen generate && open AssemblyEmpire.xcodeproj`.

## Игра

- **Бур** — ставится на залежь (железо, медь, камень, уголь), выдаёт руду по белой стрелке.
- **Конвейер** — прокладывается свайпом.
- **Печь** — руда → пластины, камень → кирпич, пластины + уголь → сталь.
- **Сборщик** — шестерни, провода, микросхемы, каркасы, моторы.
- **Сплиттер** — делит поток на три стороны.
- **Рынок** — продаёт всё, что в него попадает.

9 целей с наградами, 4 ветки улучшений, автосохранение.
